# Mid-Semester Exam Duty Adjustment Helper  
**Manav Rachna University – Invigilation Duty Chart (21–25 September 2026)**

This repository helps faculty members **find free colleagues** for duty adjustments during the Mid-Semester Examinations (Odd Semester 2026-27).

---

## How to use (for faculty)

1. Open the live page: **[index.html](index.html)** (or enable GitHub Pages and open the root URL).
2. Select the **Date** and **Slot** (Morning / Afternoon / Evening).
3. The page shows all faculty with their contact numbers.
4. **Cross-check the original Duty Chart PDF** – a tick (✓) means the person is already on duty (busy). No tick = free and available for adjustment.
5. Contact the free faculty directly using the phone number shown.

## Important Disclaimer

- The interactive page lists **all** Flying Squad & Invigilation faculty with contacts.
- **Always verify free slots from the original PDF** before confirming any adjustment.
- Fixed responsibility staff (Centre Superintendent, Asst. Superintendents, Block In-charges, Control Room Supporting Staff, COE Office) are **not available** for adjustment.

## How to host on GitHub Pages

1. Create a new repository (or use this one).
2. Upload all the files.
3. Go to **Settings → Pages**.
4. Source = Deploy from branch `main` / root.
5. Share the resulting URL with all faculty.
